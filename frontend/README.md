# Website Desa - Frontend (Vite)

Jalankan proyek ini DI KOMPUTER LOKAL (bukan lewat preview artifact Claude),
karena perlu mengakses backend di `http://localhost:4000` di mesin yang sama.

## Cara jalan

1. `npm install`
2. Pastikan backend (`website-desa-backend`) sudah jalan di `http://localhost:4000`
3. `npm run dev` -> buka `http://localhost:5173`

Kalau backend nanti dipindah ke domain lain, ubah `API_BASE` di bagian atas `src/App.jsx`.
